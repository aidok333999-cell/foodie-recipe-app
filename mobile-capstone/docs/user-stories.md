# Foodie Mobile Capstone — Nine User Stories

1. **Registration:** As a new user, I want to create an account using username, email and password so that I can personalize my experience. Acceptance: invalid fields produce an error and valid fields create a local demo account.
2. **Login:** As a registered user, I want to sign in with email and password so that I can access the recipe app. Acceptance: incorrect credentials show an error.
3. **Recipe discovery:** As a user, I want to browse a home feed of recipes so that I can choose what to cook.
4. **Recipe details:** As a user, I want to open a recipe and read its instructions so that I can prepare it.
5. **Favorites:** As a user, I want to save and remove recipes from favorites so that I can revisit them.
6. **Persistence:** As a user, I want my favorites and preferences to remain after restarting the app so that I do not lose them.
7. **External API:** As a user, I want to fetch recipe data from TheMealDB so that I can discover new meals.
8. **Settings:** As a user, I want to change theme and sign out using a settings menu so that I can control my experience.
9. **Notifications:** As a user, I want to request a test cooking reminder so that I can verify notification functionality.

These stories correspond to a demonstration application; authentication is local-only, not production secure.
