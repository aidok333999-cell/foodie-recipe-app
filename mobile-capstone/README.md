# Foodie — Smart Recipe Discovery & Meal Planner

React Native / Expo mobile capstone starter for Coursera's 28-item final project.

## Structure
- `App.js`: signup, login, home, details, favorites, persistence, API, settings, notifications
- `package.json`: Expo dependencies
- `docs/user-stories.md`: nine user stories

## Running
Run `npm install` then `npx expo start` in this directory. Use a compatible Expo Go or Expo web development environment.

## Caveats
The demo stores credentials locally, including the password; **do not use real credentials**. The project has not been independently run or tested. Notification behavior depends on device permissions and platform support. Do not claim a notification succeeded until observed on a real device.

## Evidence still required
The rubric requires two Figma screenshots, signup/login and error screenshots, home/detail/navigation screenshots, persistence and API evidence, settings/menu screenshots, and notification configuration and actual alert evidence. These must be captured from the functioning app, not invented. GitHub URLs alone do not satisfy screenshot tasks.

This project is placed in a dedicated subfolder to avoid overwriting existing Foodie coursework.
